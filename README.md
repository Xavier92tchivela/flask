# DoctorIA - Sistema Médico com Inteligência Artificial

Sistema completo de gestão médica com integração à API Gemini do Google para geração automática de receitas.

## 🚀 Funcionalidades

- ✅ **Multi-perfil**: Médico, Paciente, Analista, Administrador
- ✅ **Consultas**: Agendamento, confirmação, realização
- ✅ **Sinais Vitais**: Registro com classificação automática (PA, FC, FR, Temperatura, SpO2, Glicemia, Peso)
- ✅ **Pedidos de Análise**: Solicitação e acompanhamento de exames
- ✅ **IA Gemini**: Geração automática de receitas baseada em diagnóstico e sintomas
- ✅ **Receitas em PDF**: Formatação profissional com validade
- ✅ **Dashboard**: Estatísticas e acompanhamento

## 🛠️ Tecnologias

- **Backend**: Python/Flask
- **Banco de Dados**: MySQL (Aiven) / PostgreSQL (Render)
- **IA**: Google Gemini API
- **Frontend**: HTML, CSS, JavaScript, Bootstrap
- **PDF**: ReportLab
- **Hospedagem**: Render

## 📋 Pré-requisitos

- Python 3.8+
- MySQL ou PostgreSQL
- Chave da API Gemini
